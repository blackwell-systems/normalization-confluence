# Gap 3, two tokens: SAT decision, mined invariants, and the proof now in `LocalTwoToken.v`

Date: 2026-10-05. Setting and notation as in `REPORT.md`: Boolean networks, (A) is no cycle in any
local graph G(x), (B) is out-degree at most one in every G(x). A token is an unstable vertex.
Under (B) and no self-loops the token count never increases (`ucnt_mono`), so it is constant on a
closed asynchronous run. The question for k = 2: is there a closed asynchronous run whose states
all have exactly two unstable vertices?

**Result.** No, for every n. The proof below is mechanized, axiom-free, in `coq/LocalTwoToken.v`
(`two_token_closed`, `two_token_fair_settlement`). The SAT decision and the invariant mining that
led to it are recorded here so they can be reproduced. Gap 3 stays open: three or more tokens are
not covered.

## 1. SAT decision for k = 2

`run_k2.py n opts solver` searches for a network with (A) and (B) and a nonempty set C of states,
each with a chosen state-graph edge into C, such that every state of C has exactly two unstable
vertices. Sound strengthenings, as in `run_strong.py`:
- `sym`: a state of C is 0 and its chosen edge flips vertex 0 (translation and permutation
  symmetry).
- `tok`: every chosen edge passes a token (implied by "exactly two" at both ends; kept as a hint).
- `alldir`: every vertex is flipped on some chosen edge. Sound once every smaller n is decided: a
  k = 2 closed run that flips only the vertices in I is a closed run of the subcube network on I
  with 2 minus (tokens outside I) tokens, and 0 or 1 tokens are excluded by `one_token_closed`.
- `rank`: (A) encoded by a ranking of each G(x) (order encoding) instead of one clause per
  elementary cycle; under (B) both say that each G(x) is acyclic.

Encoding check: with (A) replaced by "no self-loops" (`noA`), the same query is SAT at once for
n = 3 to 6 (the strengthenings do not make it trivially UNSAT).

below.

## 2. Mined invariants

Samples: SAT-sampled (A)+(B) networks with random phases (`sample.py`; 2000 networks for each of
n = 4, 5, 6 and 300 for n = 7), and networks forced to contain a long two-token walk
(`sample_rich.py`; n = 5 with 6 forced moves, n = 6 with 8). Every count-preserving move between
two-token states was tested (`mine.py`, `mine2.py`). Over n = 4 and 5 alone that is 27,105 moves.

| Candidate (on the token pair {a, b} at x) | Behaviour on count-preserving moves | Outcome |
|---|---|---|
| distance between the tokens in the forest G(x) (undirected) | rises and falls (n = 4: 4,218 down, 2,270 up) | fails |
| one token is an ancestor of the other | never reverts in the samples | holds at every state with one good and one bad token (the good token's out-path reaches the bad one, a consequence of rigidity below); not a potential |
| a common downstream receiver (same tree of G(x)) | rises and falls | fails |
| sum of out-path heights (from `REPORT.md`) | rises on 84 moves at n = 4, 26 at n = 5 | fails |
| maximum height | rises on 182 moves at n = 4 | fails |
| reach set (union of the two out-paths), size | never rises at n = 4 and 5; rises on 31 moves at n = 6 | fails |
| reach set, inclusion R(y) inside R(x) | fails on 286 moves at n = 4 | fails |
| upstream cones, size; do they meet | rise and fall | fails |
| number of arcs, arcs from D(x), arcs into D(x) | rise and fall | fails |
| d(x, p), p the fixed point | +1 or -1 on every move | not monotone (it is the bookkeeping in the proof) |
| collision count | 0 on every closed two-token run (a collision drops the count) | vacuous |
| number of good tokens g(x): tokens whose vertex disagrees with p | never rises (0 rises in all samples) | **holds for k = 2** (proved); fails for k = 3 |

SAT falsification of the surviving candidate (`fals_good.py`): with p = 0 (by translation), a
state x with tokens {v, b}, v agreeing with p, an arc v -> w in G(x) with w stable at x, and w
disagreeing with p. UNSAT for every case at n = 4, 5, 6 and 7 (each under 0.6 s). With three
tokens the same query is SAT at n = 4: f_0 = (x1 or x2) xor x3, f_1 = f_2 = 0, f_3 = x1 and x2,
with fixed point 0000. At x = 1110 (bits written x0 x1 x2 x3) the tokens are 1, 2 and 3; vertex 3
agrees with p, its out-arc in G(x) goes to the stable vertex 0, and firing it passes the token to
0, which disagrees with p (x0 = 1). Conditions (A) and (B) hold (checked by `verify.py`).

## 3. The proof for k = 2

Let p be the unique fixed point (Shih and Dong) and D(x) the set of coordinates where x differs
from p. A token at v is good when v is in D(x) and bad otherwise; F is the synchronous map.

1. **At least one good token** (`not_both_bad`). F(x) xor p = D(x) xor U(x). If both tokens were
   bad, |F(x) xor p| = |D(x)| + 2, against non-expansiveness d(F x, F p) <= d(x, p).
2. **Rigidity** (`tight`, `tight_arc`, `head_arc`). With one good token b and one bad token v,
   |F(x) xor p| = |D(x)|. For j in D(x), non-expansiveness at flip j x and the triangle inequality
   force j to have an out-arc in G(x), and its target i to satisfy F_i(x) <> p_i: otherwise
   d(F(flip j x), p) = |D(x)| + 1 > |D(x)| - 1. The vertices with F_i(x) <> p_i are D(x) minus b,
   plus v. So every vertex of D(x) + {v} has an out-arc into D(x) + {v} except possibly v; if v
   also points into D(x), G(x) has a cycle. Hence **a bad token never points into D(x)**.
3. **Types are invariant** (`G1_T`, `G1_H`). On a move that keeps two tokens, a bad token passes
   to a bad receiver (step 2), and a good token passes to a good receiver (step 1, since the other
   token is bad). So g(x) never rises, and on a closed run it is constant.
4. **g = 2 throughout** (`run_bad_or_dec`): every move fires a good token, d(x, p) strictly
   decreases, and the run cannot close.
5. **g = 1 throughout.** Label moves T (the good token fires, d decreases) and H (the bad token
   fires, d increases); a closed run has equally many of each (`W_dp`).
   - `swap_TH`: T then H from x can be replaced by H then T, reaching the same state with two
     tokens throughout. The bad token has an out-arc at x (else a token would be lost, and
     `ucnt_mono` gives a contradiction at the common end state), and by step 2 it does not point
     at the good token. (H then T cannot always be swapped: the good token may point straight at
     the bad one.)
   - `W_sort`: move every H to the front: the run becomes H^h T^h from x. Rotated to start at
     the state between the blocks, it is T^h H^h, a closed run from z.
   - `W_pullH`, `W_main`: pull the first H to second place, T H T^(h-1) H^(h-1), and repeat. The
     run becomes (T H)^h. From a state with tokens {b, v}, "fire b, then v" ends at
     x xor {b, v} = F(x) (`F_two`). So F^h(z) = z with h >= 1, while z has two unstable vertices
     and is not fixed: against `sync_orbit_fixed`.

Steps 1 to 5 were checked on the sampled instances (`checkproof.py`: g >= 1, rigidity, g never
rising, the swap, and "T then H = F"), with no failure.

## 4. What does not carry over to three tokens

- Step 3 fails: a bad token can pass to a good receiver (the n = 4 witness above), so the token
  types are not invariant and g can rise.
- Step 5's swap fails exactly when the moving token's vertex points straight at another token.
- Rigidity needs equality in non-expansiveness (as many bad tokens as good ones); with three
  tokens at least two are good and the inequality is strict.
