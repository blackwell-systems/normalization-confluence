# Unary nat recursion gogen accepts (see refuseUnary in gogen/main.go), and why
# each is harmless. Format: <extraction json> <function> <reason>. gogen reads
# this file (-allow-unary-file) and so do its tests; any other unary recursion
# is refused.
#
# The checkers. None recurses on a number that grows with the state space
# without being a tail call, so no stack grows with the input, and each runs
# a bounded number of steps:
oracle_core.json chunkT      fuel = list length; tail call (accumulator)
oracle_core.json depthF      fuel; stops after at most 5 steps at 2^20 keys; tail call
oracle_core.json powF        fuel; stops with depthF; tail call
oracle_core.json levels      trie depth, at most 5 at 2^20 keys
oracle_core.json zt          trie depth, at most 5 at 2^20 keys
oracle_core.json skipn       at most 16 per trie node; tail call
oracle_core.json nth         list index, below the list's length; tail call
oracle_core.json seq         number of events (allPairs); not tail, depth = events
oracle_core.json pairsAll    number of events; tail call (accumulator)
oracle_core.json pairsRow    number of events; tail call (accumulator)
oracle_core.json natZF       fuel; halves the number each step, so log2 steps
oracle_core.json layer       one variable's domain size; tail call (accumulator)
oracle_core.json normalize   repair fuel; stops at the first valid state; tail call
oracle_core.json rd          variable index; recursion on the valuation list (number of variables)
oracle_core.json wr          variable index; recursion on the valuation list (number of variables)
oracle_core.json repeat      number of variables (zeroV)
#
